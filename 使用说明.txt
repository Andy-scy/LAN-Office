【第 0 章】先认识一下：这是个啥？

  在你家 / 班级 / 办公室的一台 Windows 电脑上开一个小网站，
  同一个 WiFi 下的手机、平板、其他电脑打开这个网址，就能：

  · 一起编辑同一个 Word / Excel / PPT（改动实时互相可见）
  · 开"修订模式"，谁写的哪一段按颜色+名字标出来
  · 发问卷做小测，成绩柱状图和明细当场出
  · 一切自动保存、自动备份，不怕断电、不怕手滑

  你只需要记住两个文件：
  · setup.bat —— 第一次使用时双击（装环境）
  · start.bat —— 以后每天双击（开门营业）


【第 1 章】开始之前：确认三件事

  1. 有一台 Windows 电脑当"主机"（开网站的那台）。
     建议：Win10/11 64 位、内存 4GB 以上、硬盘剩余 5GB 以上。
  2. 所有要用的设备（手机/平板/电脑）连同一个 WiFi。
  3. 主机使用期间别关机、别睡眠。


【第 2 章】第一次使用：装环境（只做一次）

  第 1 步：双击 setup.bat
    黑窗口会自动做三件事：
    ① Node.js：没装就自动下载绿色版（约 35MB，不动系统）
    ② 项目依赖
    ③ 检查 ONLYOFFICE 编辑引擎（在线编辑 Office 必须有它）

  第 2 步：装 ONLYOFFICE 编辑引擎（向导提示"未检测到"时）
    · 向导问"现在自动下载并启动官方安装器吗？"→ 按 Y
    · 下载完成后安装窗口会自动弹出：
        勾选同意协议 → 点 Install（安装）
        Windows 蓝色提示"是否允许" → 点"是"
        最后点 Finish（完成）
    · 装完不用做任何事，黑窗口会自己检测到并打 √

  第 3 步：看到"环境检查完成！"就成了。
  ※ 某一步失败？重新双击 setup.bat 再来一次即可，
    下载支持断点续传，不会从头开始。


【第 3 章】每天开门营业：start.bat

  1. 主机双击 start.bat，黑窗口出现：

       本机访问:    http://localhost:3000
       局域网访问:  http://192.168.3.97:3000  ← 其他设备用这个

  2. 主机自己会自动打开浏览器；其他设备把这个网址
     输到浏览器地址栏即可。
  3. 端口不是 3000？说明被占了，软件自动换成 3001、3002……
     一切以黑窗口显示的为准，不用管。

  ★ 用得好：把 start.bat 的快捷方式发到桌面，
    以后双击桌面图标就行。


【第 4 章】文件管理：8 个常用动作

  4.1 上传（三种方式，哪种顺手用哪种）
      ① 点"上传文件"按钮，选文件；
      ② 把文件从文件夹直接拖到网页里松手；
      ③ 手机/平板上点右下角的紫色悬浮"上传"球。
      支持一次选多个文件，批量上传。

  4.2 下载
      文件卡片上的"↓"图标 = 下载到本地，
      想发给微信好友就用这个。

  4.3 重命名
      点"✎"图标 → 输入新名字 → 保存。
      不用写扩展名（.docx 会自动保留）。

  4.4 删除
      点"🗑"图标 → 确认删除。
      注意：有别人正在编辑时会提示"先关闭再删"，这是保护。

  4.5 新建空白文档
      点"＋ 新建"→ 选 Word / Excel / PPT → 起个名 → 创建并打开。
      适合临时起意写点东西，不用满电脑找模板。

  4.6 搜索
      右上角搜索框输入文件名关键字，即时过滤。

  4.7 备份历史与恢复（后悔药）
      点文件卡片上的"时钟"图标 → 能看到每一次保存前的版本；
      选一个点"恢复"，文件就回到那一刻。
      默认每个文件保留最近 30 份备份。

  4.8 卡片上的信息怎么看
      图标颜色 = 类型（蓝 W 是 Word，绿 X 是 Excel，红 P 是 PPT）
      "N 人正在编辑" + 彩色头像 = 谁此刻正在改这个文件
      （鼠标放到头像上还能看到昵称和设备名）

  ★ 用得好：文件名写清楚"班级+内容+日期"，
    例如"初一3班-第一章测验-0919.docx"，人多了也不乱。


【第 5 章】多人协同编辑：像共写一块黑板

  5.1 怎么一起改一个文件
      大家各自点开同一个文件 → 自动进入同一个编辑会话。
      你打字对方马上看到，对方删字你也马上看到。

  5.2 自动保存的时机
      · 停手几秒 → 自动保存一次；
      · 最后一个人关闭页面 → 立即保存；
      · 编辑器顶栏会显示"● 有未保存的更改 / ✓ 已自动保存"。

  5.3 看谁在编辑
      文件卡片上有彩色头像和"N 人正在编辑"；
      编辑器里每个人的光标自带昵称和颜色。

  ★ 用得好：多人同时改同一个段落容易"打架"，
    分工时最好一人负责一块（你写第 1 节，我写第 2 节）。


【第 6 章】修订模式：谁写的哪一段，一目了然

  6.1 怎么开
      打开 Word 文档 → 点顶栏"🖊 修订模式：关"→ 变成"开"。

  6.2 开了之后什么样
      每个人插入/删除的文字都带作者专属颜色，
      鼠标停上去显示是谁、什么时候改的；
      右下角出现"审查更改"面板。

  6.3 老师怎么采纳
      "审查更改"面板里有 ◀ ▶ 翻阅按钮和"同意 / 否决"：
      满意就"同意"（变成正式内容），不满意"否决"（还原）。

  6.4 什么时候该用
      · 收作业：学生各自改一篇稿，老师逐处点评采纳；
      · 多人合稿：谁加的哪句话清清楚楚，不会互相覆盖。
      再点一次按钮就切回自由编辑。
      ※ Excel 和 PPT 没有修订机制（格式限制），
        它们仍然用彩色光标区分不同的人。

  ★ 用得好：收作业时让学生都用修订模式写，
    你批改时一目了然，还能挑着采纳。


【第 7 章】问卷：5 分钟做个课堂小测

  7.1 出卷（老师）
      首页右上角点"📋 问卷"→"新建问卷"：
      写标题 → 加题目（每题写题干 + 2~6 个选项，可加多题）
      → 点"发布问卷"。完成。

  7.2 答题（学生）
      问卷列表里点右侧蓝色"填写"按钮 → 逐题点选答案
      → 提交。提交后想改？再进一次、改完重新提交即可
      （以最后一次为准）。

  7.3 看统计（老师）
      自己创建的问卷上点"📊 查看结果"：
      · 每道题的柱状图：各选项多少人选、百分比多少；
      · 作答明细：谁、用哪台设备、几点交的、选了什么；
      · 每 5 秒自动刷新，学生边答你边看。

  7.4 导出 CSV
      结果页点"导出 CSV"→ 下载表格文件，
      Excel / WPS 双击打开，方便存档和打分。

  7.5 用得好的窍门
      · 题目选项写具体（别只写"A/B/C/D"），
        学生一眼看懂，你统计时也不用翻卷子；
      · 课上小测 3~5 题刚刚好；
      · 学生答完马上看柱状图讲评，效果最好；
      · 问卷只在创建者的列表里显示"查看结果"，
        学生看不到别人的答案，放心用。


【第 8 章】昵称与设备名称

  点右上角自己的头像，可以同时改两样：

  · 昵称：如 Blue Fox（协同时光标旁显示的名字）
  · 设备名称：如 电脑-6CU / 手机-A1（按设备类型自动生成）

  在"在线人数"（鼠标悬停）、文件编辑人数、问卷答卷明细里
  都能看到，分得清是谁的哪台设备。

  ★ 用得好：家里几口人共用时，设备名直接写人名
    （"爸爸的手机""姐姐的平板"），一眼就知道谁在改。


【第 9 章】手机 / 平板 / 电脑：三套界面（自动切换）

  · 电脑打开 → 鼠标版：多列文件格、悬停出按钮，和原来一样；
  · 手机打开 → 触屏版：单列大卡片、右下角悬浮"上传"球、
    底部"文件 / 问卷"导航栏；文件操作点卡片右边的"⋯"弹出；
  · 平板打开 → 触屏版：双列大按钮网格，同样有悬浮球和底栏。

  一切自动识别，不用任何设置。
  万一某台设备识别不对，网址后面加上
  ?ui=mobile（或 tablet / desktop）即可强制切换。


【第 10 章】数据在哪、怎么备份

  · 所有文件都在项目文件夹的 data\ 目录里：
      data\documents\  正式文件（手动丢进去也能被识别）
      data\backups\    每次保存前的自动备份
      data\surveys\    问卷和答卷
  · 整体备份 = 关闭服务后复制整个 data 文件夹到 U 盘。
  · 换电脑迁移 = 把整个 LAN Office 文件夹拷过去
    （记得排除 data 里不想带走的旧文件）。


【第 11 章】常见问题（对症下药）

  问：手机打不开网址？
      ① 确认连的是同一个 WiFi；
      ② 主机第一次运行时防火墙提示点"允许访问"；
      ③ 网址以黑窗口显示的为准。

  问：能打开列表，但文件提示"编辑引擎未连接"？
      主机上的 ONLYOFFICE 没装好或没启动。
      重跑 setup.bat 检查，或重启主机再试。

  问：编辑器报 Token / JWT 错误？
      看 README.md 搜"JWT"两个字，按说明把密钥填进
      config\config.json 再重启。

  问：端口不是 3000？
      被占用自动换号了，以黑窗口显示的为准。

  问：用完怎么关？
      黑窗口按 Ctrl+C 或直接关掉窗口；
      已保存的内容都在，下次 start.bat 接着用。

  问：电脑重启后要重新装吗？
      完全不用。双击 start.bat 就能用。


【第 12 章】分组与权限：每组只能动自己组的文档

  适合班级里分小组、或不同班级共用一台主机时"各管各的"。

  老师这样操作（一次性设置）：
  1. 打开网站，点右上角"🛠 管理面板"（或地址后加 /admin.html）。
  2. 输入教师管理密码（启动黑窗口里有显示，默认 1234；
     想改密码：打开 config\config.json 改 teacherPassword 后重启）。
  3. 勾选"启用分组访问控制"。
  4. "分组管理"里创建分组（如"一组""二组"），
     每个组会得到一个 4 位加入码——投在黑板上或念给学生。
  5. "文件归组"里把每个文档分给对应的组；
     不归组（公共）的文档 = 所有人都能编辑。

  开启后的规则：
  · 学生第一次打开网站，会看到"🚪 加入分组"，
    输入加入码就进入对应组（手机电脑同一个码都行）；
  · 学生只能编辑"本组文档 + 公共文档"；
  · 其他组的文档：你在面板里可以选"完全隐藏"或"可查看（只读）"；
  · 上传 / 新建 / 删除 / 重命名 / 恢复备份 / 创建问卷
    都只有教师能操作；
  · 学生点右上角"👥 组名"可以换组或退出。

  用得好：
  · 一个班建一个组，加入码投一次全班就都进了；
  · 想临时公开某个文档给全班改？把它设回"公共"；
  · 教师身份只登录你自己的电脑，学生机器不要输教师密码；
  · 想恢复"谁都能随便改"的旧模式：面板里取消勾选即可，
    所有文件和分组都保留。


【第 13 章】老师实战建议（怎么用好）

  · 课前 5 分钟：主机双击 start.bat，把局域网网址
    投到黑板上，学生扫码/输入即进。
  · 收作业：新建一个"作业-日期.docx"，开修订模式，
    学生各自进去写，你课后逐条采纳/否决，谁写的都清楚。
  · 随堂小测：问卷 3~5 题，学生两分钟答完，
    柱状图当场讲评，错的多的题重点讲。
  · 分组协作：一组一个文档，组内自由编辑、组间互不影响；
    文件名按"组名-任务"起，方便辨认。
  · 防手滑：重要文档改动前先看一眼"备份历史"，
    改砸了随时恢复；关键节点也可以手动下载一份存档。


【附】注意事项

  · 主机别睡眠：控制面板 → 电源选项 → "使计算机进入
    睡眠状态"设为"从不"最省心。
  · 只有连同一 WiFi 的人能访问，互联网上的陌生人进不来。
  · ONLYOFFICE 装好后开机自启（后台服务），不影响电脑正常使用。
