  LAN Office 使用说明（新手一看就会版）
════════════════════════════════════════════════════════════

【这是个啥？】

  在你家 / 班级 / 办公室的一台 Windows 电脑上开一个小网站，
  同一个 WiFi 下的手机、平板、其他电脑打开这个网址，
  就能一起编辑同一个 Word / Excel / PPT 文件：

  · 你的改动，别人屏幕上马上能看到
  · 别人的改动，你也能马上看到
  · 改完自动保存，改错可回退到历史备份


【开始前，确认 3 件事】

  1. 有一台 Windows 电脑当"主机"（就是开网站的那台）。
     建议：内存 4GB 以上，硬盘剩余 5GB 以上，Win10/11 64 位。
  2. 所有要一起用的设备（手机/平板/电脑），
     连的是同一个 WiFi（同一个路由器）。
  3. 主机电脑在使用期间别关机、别让它睡觉（睡眠）。


【第一次使用：装环境（只装一次，以后不用再装）】

  第 1 步：双击 setup.bat
    会弹出黑色窗口，跟着提示走就行。它会自动做 3 件事：

    ① Node.js：没装的话自动下载绿色版（约 35MB，不用装进系统）
    ② 项目需要的小组件
    ③ 检查 ONLYOFFICE 编辑引擎（在线编辑 Office 必须有它）

  第 2 步：装 ONLYOFFICE 编辑引擎（setup.bat 提示"未检测到"时）
    · 黑窗口会问："现在自动下载并启动官方安装器吗？"
      → 按 Y 键（就是"好"）。
    · 它会下载安装包（约 1GB，网速慢就多等等），
      下完自动弹出安装窗口。
    · 安装窗口里这样点：
        勾选"我同意 / I accept" → 点 Install（安装）
        Windows 弹蓝色提示问"是否允许…" → 点"是"
        最后点 Finish（完成）
    · 装完不用做任何事，黑色窗口会自己检测到并打 ✓。

  第 3 步：看到"环境检查完成！"就成功了。
    它问"是否现在启动 LAN Office？"→ 按 Y，进入下面的日常使用。

  ※ 如果某一步下载失败，重新双击 setup.bat 再试一次即可。


【以后每天怎么用（就两步）】

  第 1 步：主机上双击 start.bat
    黑窗口会出现类似这样的字：

      本机访问:    http://localhost:3000
      局域网访问:  http://192.168.3.97:3000   ← 其他设备用这个

    记下"局域网访问"后面的网址（每家的数字不一样，
    以你黑窗口里显示的为准）。

  第 2 步：其他设备打开这个网址
    手机/平板：连上同一个 WiFi → 打开浏览器（Safari/Chrome 都行）
    → 在最上面的地址栏输入那个网址 → 进入文件页面。

    第一次打开时，页面会让你有个随机名字（比如 Blue Fox），
    想改就点右上角自己的名字。


【怎么一起编辑同一个文件】

  1. 任何人在网页上点"上传文件"，把 Word/Excel/PPT 传上去；
     或者点"新建"直接建一个空白文档。
  2. 每个人点开同一个文件 → 自动进入同一个编辑会话。
  3. 你打字，别人马上看到；别人改，你也马上看到。
     文件列表上会显示"N 人正在编辑"。
  4. 停手几秒会自动保存；最后一个人关闭页面时也会保存。
  5. 改错了？点文件卡片上的"时钟"图标，
     里面有每次保存前的备份，选一个点"恢复"就回去了。


【修订模式：看清每段是谁写的】

  打开 Word 文档后，点顶栏的"🖊 修订模式：关"，
  变成"修订模式：开"之后：

  · 每个人写的字都带自己的颜色，鼠标停上去能看到是谁写的
  · 老师在"审查更改"面板里可以逐条"同意"或"否决"每处修改
  · 再点一次按钮就切回普通编辑

  （Excel 和 PPT 没有修订机制，这是格式本身的限制，
   它们仍然用彩色光标区分不同的人。）


【问卷：课堂小测、收集意见】

  1. 首页右上角点"📋 问卷"进入问卷页面。
  2. 老师点"新建问卷"：写标题、加题目和选项（可加多题）→ 发布。
  3. 学生打开同一个网址 → 问卷页里点"填写"→ 选答案 → 提交。
     提交后还能修改重交（以最后一次为准）。
  4. 老师点"查看结果"：每道题的票数柱状图一目了然，
     下面还有"谁用了哪台设备、选了什么"的明细，每 5 秒自动刷新。
  5. 点"导出 CSV"可以把全部答卷下载成表格文件，
     用 Excel / WPS 直接打开。


【设备名称：区分谁的哪台设备】

  点右上角自己的头像，可以同时改两样东西：

  · 昵称：如 Blue Fox（协同时光标旁显示的名字）
  · 设备名称：如 电脑-6CU / 手机-A1（自动按设备类型生成）

  在"在线人数"（鼠标悬停）、文件编辑人数、问卷答卷明细里
  都能看到设备名称，再也不怕分不清是谁的哪台设备。


【常见问题】

  问：手机打不开网址？
    答：① 确认手机和主机连的是同一个 WiFi；
        ② 主机第一次运行时，Windows 弹出的防火墙提示要点
           "允许访问"（勾选"专用网络"）；
        ③ 网址以主机黑窗口显示的为准。

  问：文件列表能打开，但打开文件提示"编辑引擎未连接"？
    答：主机上的 ONLYOFFICE 没装好或没启动。
        重新双击 setup.bat 检查一遍，或重启主机再试。

  问：黑窗口显示的端口不是 3000？
    答：3000 被别的程序占了，软件自动换成 3001、3002……
        以黑窗口显示的网址为准就行，不用管。

  问：网页上有红字说 Token / JWT 错误？
    答：看项目文件夹里的 README.md，搜"JWT"两个字，
        按说明把密钥复制到 config\config.json 里，再重启。

  问：文件存在哪？想整体备份怎么办？
    答：都在项目文件夹的 data 目录里。
        整体备份 = 复制整个 data 文件夹到 U 盘/移动硬盘。

  问：用完了怎么关？
    答：在黑色窗口按 Ctrl+C，或者直接关掉黑窗口。
        关掉的只是网站，文件都好好保存着。

  问：电脑关机/重启后要重新弄吗？
    答：什么都不用重装！双击 start.bat 就又能用了。
        （只有 ONLYOFFICE 引擎开机会自动启动，不用管它。）


【友情提醒】

  · 主机开着时别让 Windows 自动睡眠：
    控制面板 → 电源选项 → "使计算机进入睡眠状态"设为"从不"。
  · 这个网址只有连你家/办公室 WiFi 的人能访问，
    互联网上的陌生人访问不到，可以放心用。
  · 主机装好 ONLYOFFICE 后，它开机时会自己启动（后台服务），
    不影响电脑正常使用。

  一句话总结：第一次双击 setup.bat，以后每次双击 start.bat，
  大家打开黑窗口里显示的网址，一起写文档。
